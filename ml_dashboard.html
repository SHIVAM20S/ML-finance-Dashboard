Machine Learning Project & Dashboard Guide

Welcome! This interactive dashboard is designed as a complete machine learning project submission covering the full ML lifecycle:

1. Dataset Generation & Ingestion:

You can generate synthetic datasets (Two Moons, Concentric Circles, Separable Blobs, Spiral XOR, Customer Churn) with customizable sample sizes and noise levels, or upload any custom CSV file.

2. Mathematical Model Architecture:

Includes Logistic Regression optimized via Batch Gradient Descent with Sigmoid activation σ(z) = 1/(1+e^-z), Cross-Entropy Loss, and L2 Regularization, as well as K-Nearest Neighbors and Decision Trees.

3. Comprehensive Visualization:

Displays a 2D decision boundary mesh, loss convergence curve over training epochs, confusion matrix with false positive/negative analysis, ROC Curve with AUC, and feature weight importances.

4. Live Inference Playground:

Allows manual testing of any feature vector with instant probability output and visual feedback on the feature map.
